# Examples

Good:
- `test: add checkout happy-path spec`
- `fix: wait for cart badge before asserting count`
- `docs: add setup steps to README`

Bad:
- `updated stuff` (vague)
- `Fixed the bug.` (past tense, period, no type)
- `feat: add login page object, fix flaky search test, update config` (does too many things; suggest splitting)
